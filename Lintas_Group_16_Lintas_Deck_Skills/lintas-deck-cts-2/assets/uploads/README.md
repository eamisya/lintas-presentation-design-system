# Client & Project-Specific Upload Assets

Place external client logos, OEM partner badges, or project-specific diagrams in this directory when preparing customized presentations.

### Best Practices:
1. **File Formats**: Transparent PNG (`.png`) or vector SVG (`.svg`) is strongly recommended.
2. **File Naming**: Use clean, descriptive names:
   - `client-logo.png`
   - `vendor-partner-logo.png`
   - `project-architecture.png`
3. **Usage Instruction for LLM**:
   Prompt your bespoke LLM:
   *"Incorporate the attached client logo from assets/uploads/ on the Cover slide secondary header rail, preserving transparent clear space and equal optical balance with the Lintas Group logo."*
