The **Lintas Presentation Design System** is an enterprise presentation craftsmanship framework and automated skill repository for **Lintas Group**. It enables team members across eight functional departments to generate human-crafted, editable, 16:9 widescreen PowerPoint presentations using bespoke Large Language Models (LLMs).

---

## 🌐 Live Skill Portal (Web Download & Guidance)

Team members do not need to install Git or Python to download their skills. Access the interactive web portal directly via GitHub Pages:

👉 **[https://eamisya.github.io/lintas-presentation-design-system/](https://eamisya.github.io/lintas-presentation-design-system/)**

Through the portal, team members can:
1. Select their **Department** and **Role / Focus** to receive an instant recommended presentation treatment.
2. Preview their visual identity, color swatches, signature diagrams, and bundled corporate assets.
3. Download ready-to-install packages in **`.zip`** (complete skill + assets), **`.md`** (system prompt), or **`-assets.zip`**.
4. Follow guided, step-by-step instructions for **Claude**, **ChatGPT**, **Gemini**, **Google Antigravity**, and **Microsoft Copilot**.
5. Use the **Client Asset Upload Workbench** to stage and validate custom customer/partner logos.

## 🎨 Dual Treatment Philosophy

Every department has two tailored presentation treatments to suit different operational scopes:

1. **Treatment 1: Executive Editorial (`-1`)**
   - *Target Audience*: Board of Directors, executive steering committees, strategic clients, public tenders.
   - *Design Treatment*: 60/40 editorial splits, full-width key takeaway banners, quiet negative space, generous breathing room, and decisive narrative progression.
2. **Treatment 2: Operational Decision Intelligence (`-2`)**
   - *Target Audience*: Weekly operations, technical queries, SLA reviews, incident post-mortems, cross-department working sprints.
   - *Design Treatment*: Denser structured layouts, systematic labeling, evidence-to-decision pathways, technical tables, and native diagram swimlanes.

## 🖼️ Approved Graphical Assets & Upload Protocol

Each of the 16 skill packages pre-bundles verified Lintas Group corporate and texture assets:

```
skill-folder/assets/
├── brand/
│   ├── lintas-group-logo.png          # Official corporate logo (transparent PNG, 460×127 px)
│   ├── lintas-closing-slide.jpg       # Back-cover lockup with Menara MTH 16th floor HQ address
│   ├── lintas-slide-master-light.jpg  # Reference light content canvas with brand footer
│   └── lintas-slide-master-cover.jpg  # Reference legacy title canvas
├── textures/
│   ├── network-globe.jpg              # Telecommunications global coordinate mesh watermark
│   ├── night-city-mesh.jpg            # Nocturnal smart-city data grid for dark divider slides
│   └── corporate-architecture.jpg     # Architectural glass tower rail for editorial splits
└── uploads/
    └── README.md                      # Instructions for staging client/vendor partner logos
```

> **Client & Partner Logo Protocol**: External client, OEM vendor, or operator logos are **not** bundled statically to maintain corporate neutrality. Instead, team members upload client logos dynamically per project (via chat attachment or `assets/uploads/`). The skills instruct LLMs to maintain transparent backgrounds, balanced optical sizing (~24–32 pt height), and strict co-branding separation.

## 🚀 LLM Installation Matrix

| AI Platform | Package File | Setup Action |
|---|---|---|
| **Claude (Web & Desktop)** | `.zip` package | **Settings** → **Capabilities** → **Skills** → Click **Add Skill** and upload `{skill}.zip`. |
| **Claude Code (CLI / SDK)** | `.zip` package | Unzip into `~/.claude/skills/{skill}/` or project root `.claude/skills/`. |
| **Google Antigravity** | `.zip` package | Unpack into your active workspace or `~/.gemini/antigravity/skills/`. |
| **OpenAI ChatGPT** | `.md` + Assets | Open Custom GPT / Project → Paste `{skill}.md` into **Instructions** → Attach assets under **Knowledge** → Enable **Code Interpreter**. |
| **Google Gemini (Gems)** | `.md` + Assets | Create new Gem → Paste `{skill}.md` into **Instructions** → Attach `lintas-group-logo.png`. |
| **Microsoft Copilot / 365** | `.md` file | Paste into Copilot Studio Custom Instructions or Personal Prompt Book. |
| **Cursor / Local LLM (Ollama)** | `.md` file | Save as `.cursorrules` or configure as `SYSTEM` prompt in Modelfile. |

### 🎯 Standard Verification Test Prompt
To verify that your bespoke LLM is strictly enforcing the Lintas Presentation Design System, start a new chat session and copy/paste:

```text
Use the lintas-deck skill to prepare a 3-slide executive presentation for Lintas Group.
Include:
1. Cover slide with official Lintas Group logo and our department primary and accent colors.
2. Content slide featuring our signature departmental visualization.
3. Closing slide displaying the Menara MTH 16th floor corporate headquarters address block.
```

**Expected Result**: The LLM outputs native 16:9 widescreen layout specs using your department's exact HEX palette, applies Aptos/Consolas typography, positions the corporate logo with proper clear-space, and concludes with the official Menara MTH 16th floor address block.

## 💻 Local Portal Setup & Development

If you prefer to run the download portal locally:

### Option 1: Double-Click Launcher (Windows)
Double-click `start_portal.bat` inside the `portal/` folder. It launches the local server and opens `http://localhost:8080`.

### Option 2: Python Command Line
```powershell
cd portal
python start_portal.py
```

### Option 3: Rebuilding the Portal Packages
If you modify any `SKILL.md` or add new assets, regenerate all 48 download packages and SHA-256 checksums:
```powershell
cd portal
python build_portal.py
```
